# Spice Delight Restaurant Menu

A static restaurant menu website for the fictional **Spice Delight** concept. It groups menu items into starters, main courses, and desserts.

## Preview

The website source is preserved in [`index.html`](index.html).

## Features

- Menu categories and item names.
- Image references for food items.
- Responsive card layout for smaller screens.
- Restaurant contact and social-link section.

## Technology

- HTML5
- CSS3

## Run Locally

```bash
git clone https://github.com/dar2006sh8an13/menu.git
cd menu
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Image Assets

The page references local image files. Keep those assets in the expected relative paths or update the image references in `index.html`. Check filename spelling, spaces, and capitalization because paths can be case-sensitive on web hosts.

## Before Publishing

Review menu descriptions, prices, restaurant details, and contact links to ensure they are accurate. Replace demonstration content with authorized information.
